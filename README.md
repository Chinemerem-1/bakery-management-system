# Bakery Management System

## Overview
A Python-based Bakery Management System developed as part of my programming learning journey and preparation for Industrial Training (IT).

## Features
- View available bakery products and prices
- Record sales transactions
- Calculate revenue automatically
- Store sales records in a text file
- View total revenue
- View sales history
- Timestamp each transaction
- Validate user input

## Technologies Used
- Python
- File Handling
- Datetime Module
- Exception Handling

## Concepts Demonstrated
- Functions
- Dictionaries
- Loops
- Conditional Statements
- File Persistence
- Input Validation

## Future Improvements
- Database integration
- Graphical User Interface (GUI)
